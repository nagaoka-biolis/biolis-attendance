シフト希望の提出マニュアル

ご自身の勤務希望を、アプリから直接ご提出いただけます。
所要時間は数分です。以下の手順にそってご入力ください。

アプリで入力した希望は、そのままシフト表（スプレッドシート）に自動で反映されます。紙やメールでのやり取りは不要です。
スマホ・PCどちらでもOK 締切前なら何度でも修正可 所要 約3分
1

アプリにログインする

下記URLを開き、ご自身のメールアドレスとパスワードでログインします。

URL：biolis-attendance.vercel.app

example@biolisclinic.com
••••••••
ログイン
初回ログインのメール・パスワードが不明な場合は、管理者（長岡）までお問い合わせください。
2

「シフト希望」の欄を開く

ログイン後の画面を下にスクロールすると、「SHIFT REQUEST — シフト希望」という欄があります。

右上のバッジで、現在の状態（未提出 / 提出済み）がひと目でわかります。

DASHBOARD
SHIFT REQUEST — シフト希望 未提出
2026年8月の希望を入力 → 「提出」で反映されます。締切：7/25まで
8/1(金)未定
8/2(土)未定
8/3(日)未定
「現在、シフト希望の受付はありません」と表示されている場合は、まだ受付が開始されていません。案内があるまでお待ちください。
3

日ごとに希望を選ぶ

各日付の右のメニューから、希望を選びます。

選択肢は 勤務希望 ／ 休み希望 ／ 未定 の3つ。勤務希望を選ぶと、出勤・退勤の時刻を入力できます。

DASHBOARD
8/2(土) 勤務希望 出勤10:00 退勤19:00
8/3(日)休み希望
8/4(月)未定
↑「勤務希望」を選ぶと、出勤・退勤の時刻欄があらわれます
未定のままの日は提出されません。勤務希望・休み希望を入力した日だけが反映されます。
4

「シフト希望を提出」を押す

入力が終わったら、欄の一番下にある金色のボタンを押します。

シフト希望を提出
✓ シフト希望を提出しました（スプレッドシートに反映済み）

上のように緑色のメッセージが出れば提出完了です。バッジも「提出済み」に変わります。

5

修正したいとき（締切前）

締切前であれば、何度でも入力し直して再提出できます。

内容を変更して、もう一度「シフト希望を提出」を押すだけで上書きされます。

締切を過ぎると入力欄がグレーになり、「締切後」と表示されて変更できなくなります。変更が必要な場合は管理者までご連絡ください。

ご確認いただきたいこと

  • 締切にご注意ください。受付欄に表示される「締切：◯/◯まで」を過ぎると提出・修正ができません。
  • 「未定」の日は提出されません。勤務・休みの希望がある日を選んでご入力ください。
  • 提出内容はシフト表に自動反映されます。別途メールや紙でのご提出は不要です。
  • ご不明点は管理者（長岡）まで。ログインできない、締切後に修正したい等、お気軽にご連絡ください。
